# Встроенный плеер для торрентов Lampa

`internal-torrent-player.js` — небольшой адаптер для Android Lampa 3.x.
Перед запуском торрента он выбирает HTML5-плеер через публичный
`Lampa.Player.runas('inner')`. Остальные типы видео не затрагивает.
Код не делает сетевых запросов, не меняет список расширений или историю.

Это обход ограничения маршрутизации старой Android-оболочки через поддерживаемый
API выбора плеера, а не добавление кодеков. Форматы видео/аудио, не поддерживаемые
WebView телевизора, могут не воспроизводиться. GStreamer и сервер не устанавливаются.
Адаптер выставляет `player_segments_skip=auto`. Для получения таймкодов нужен
отдельно установленный Segment Source; разметка существует не для всех видео.

Пока адаптер подготовлен локально, не опубликован и не установлен.
Для отмены маршрутизации после установки отключите адаптер в «Расширениях».

Первичное основание API: [Player.runas / Player.play](https://github.com/yumata/lampa-source/blob/main/src/interaction/player.js).

## Возобновление торрентов

`torrent-resume.js` сохраняет последний выбранный torrent для карточки фильма или
сериала. Для сериала запись ведётся отдельно по каждому сезону: раздача `S01–S03`
привязывается к сезонам 1, 2 и 3, а раздачи отдельных сезонов не смешиваются.
При следующем открытии списка сохранённый результат выбирается автоматически;
если его больше нет среди результатов, остаётся обычный список.

Плагин не меняет маршрут воспроизведения и не подменяет плеер. Точное продолжение
с секунды зависит от выбранного плеера и возможностей TorrServer; для Lampa HTML5
прогресс хранится штатным таймлайном, а для внешнего Android-плеера доступно только
то, что сохраняет сам TorrServe/плеер.
