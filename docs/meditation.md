# Живые сцены · медитация

В Android-версии 0.5.0 есть отдельный режим только с частицами. Изображения,
цитаты и собственные фразы в его очередь не попадают и не загружаются.
Старый набор доступен отдельно через «Режим заставки → Изображения и цитаты».

По умолчанию включены все восемь сцен, длительность каждой — один час.
Можно выбрать 15 минут, 30 минут, один час, три часа или «Не переключать».
В последнем случае при запуске остаётся одна из отмеченных сцен; при включённом
случайном порядке она выбирается случайно. Если снять все отметки, остаётся
«Дыхание». Вход и выход сцены занимают по 20 секунд.

Для просмотра конкретной сцены выберите её в «Сцена для предпросмотра» и нажмите
«Показать выбранную сцену». Такой предпросмотр не переключается автоматически;
«Назад» возвращает к настройкам. Он не меняет выбор сцен системной заставки.

|---|---|
| [Дыхание](screenshots/meditation-0.5/breathing.png) | Облако сжимается и расширяется, медленно меняя пропорции и вращение. |

| [Память стенок](screenshots/meditation-0.5/echoes.png) | Касания вихрей границ создают распространяющиеся и отражённые волны. |
| [Песок без верха и низа](screenshots/meditation-0.5/sand.png) | Направление оседания поворачивается, а дюны постепенно перетекают к другой стенке. |
| [Рождение кристалла](screenshots/meditation-0.5/crystal.png) | Кристалл растёт, держится и тает; следующая пятиминутная глава изменяет рисунок ветвей. |
| [Два течения](screenshots/meditation-0.5/currents.png) | Две группы частиц разной яркости и размера образуют ленты, смешиваются и разделяются. |

Это художественные модели движения, без физической достоверности астрофизики
или взаимных столкновений всех песчинок. Они не удаляют частицы и не меняют
замкнутый прямоугольный контур. Медленные параметры накладываются на более быстрый
поток, поэтому длительная сцена не равна повторению короткого видеоролика.

## Проверка 0.5.0

Дата: 2026-09-06. Сборка, `lintDebug`, тесты движка, кеша и Android gallery smoke
прошли. `ParticleModesTest` проверяет восемь часовых сцен, полный оборот очереди,
бесконечный таймер до семи суток и конечность fade-параметров.

`GpuModeTest` запускает каждый режим с 200000 частиц. Проверены конечность
координат/скоростей и удержание внутри контура на выбранных стадиях сюжета
от 0 до 24 часов; затем сохранены кадры всех восьми сцен в 1920×1080.
Это переходы тестового времени, а не суточное испытание реальной работы.
Галерея проверена отдельно: все 100 изображений, 1000 цитат, импорт, EXIF,
ограниченный кеш и GPU/CPU сравнение (максимальная ошибка 2.8014183E-6).

APK установлен на Philips Google TV с Android12, versionCode6/versionName0.5.0.
SHA256: `93473742f17c3c58f242494b80d264497e1449bd6ed21f6df31380cf0d0cfed4`.
В системном запуске журнал подтвердил mode8 («Чёрная дыра»), duration3600,
200000 частиц, GPU Mali-G57 и поверхность3840×2160. После прогрева отмечены
интервалы по5 секунд с60.0 drawCallbacks/s, CPU submit около8.4–8.5 мс.
Это частота вызовов отрисовки, не самостоятельная выборка времён показа кадров.
Постоянные60FPS для всех восьми режимов на телевизоре не заявляются.

Ограничение1080p-композиции Philips из [проверки0.4.1](validation-0.4.1.md)
сохраняется. Установленная Mac-заставка остаётся отдельной версией без этих режимов.

## Системный сон телевизора

На проверенном Philips `screen_off_timeout=600000` запускает режим бездействия,
а `sleep_timeout=3600000` ограничивает его последующим сном примерно через час
после последней активности. Приложение не меняет эти настройки автоматически.
Для многочасового системного показа этот таймер требует отдельного выбора
пользователя. До получения ответа он оставлен прежним. Предпросмотр использует
стандартный `FLAG_KEEP_SCREEN_ON`, пока окно приложения открыто.

Основание поведения сна: [AOSP Android12 PowerManagerService](https://android.googlesource.com/platform/frameworks/base/+/android12-release/services/core/java/com/android/server/power/PowerManagerService.java).

## Воспроизведение тестов

```sh
JAVA_HOME=/path/to/jdk /bin/bash tools/test-engine.sh
# Только одноразовый эмулятор, не телевизор пользователя:
adb -s emulator-5580 shell am instrument -w -e modePreviews true \
  ru.krajcik.tvlab.particles.test/ru.krajcik.tvlab.particles.SmokeInstrumentation
```

Перед instrumentation установите оба APK после `assembleDebug` и
`assembleDebugAndroidTest`. Новый режим работает на GPU; CPU reference остаётся
для прежней галереи, а новые силы покрыты GPU-проверками инвариантов.
