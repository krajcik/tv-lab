# Механика потока: версия 0.2

Проверено 2026-09-05 по публичному HTML/JavaScript
[«Взаперти»](https://neuro-slop.ru/lab/vzaperti/). Исходный HTML получен заново
и просмотрен в браузере. Оригинальные музыка, портреты и JavaScript в APK
не включены; математическая механика реализована на Java и GLSL.

## Исправленные расхождения с 0.1

В 0.1 использовались один вихрь, общий коэффициент притяжения, длинные
накопительные следы, 16 тысяч частиц и промежуточная текстура 720p.
Это давало другое движение. В 0.2:

- Восемь вихрей с радиусами 0.15–0.32, сроком жизни 8–18 секунд, перемещением,
  отскоками, столкновениями, ударными волнами и повторным появлением.
- Поле из трёх масштабов турбулентности и многослойных спиралей. Сетка 65×49,
  билинейная интерполяция, удаление 90% среднего дрейфа.
- Индивидуальные seed, arrival, response, layer и capture для каждой частицы.
  Около 5.5% частиц остаются свободными.
- Постепенный захват с коэффициентом 2.8, освобождение с коэффициентом 7,
  пружина `30*capture³`, свобода `.28+.72*(1-capture)²`, damping `6.1*capture`.
- Первое проявление около 15-й секунды; обычный цикл 18.75 секунды, сборка
  до 4 секунд, короткое удержание 0.9 секунды и быстрое освобождение.
- Настоящие отскоки от стенок с коэффициентом 0.83 и касательным скольжением.
  Перенос на противоположный край, добавленный в 0.1, убран.
- Белый цвет, обычное alpha blending, очистка чёрным каждый кадр. Короткие
  линии показывают смещение за один кадр; framebuffer-накопления больше нет.
- Мелкие точки с компенсацией прозрачности для субпиксельного размера и
  квантованием прозрачности по десяти уровням.

Релевантные места полученной редакции HTML: координаты и частицы 219–305;
вихри 434–478; поле 480–525; фазы 545–580; интегратор, стены и видимость 614–717;
WebGL pipeline 145–208. Номера строк относятся к редакции на дату проверки.

## Осознанные отличия

Используется нейтральный режим без аудио (`energy`, `bass`, `treble`, `burst`
и другие звуковые управляющие значения равны нулю). Поэтому реакция оригинала
на конкретную песню не воспроизводится. Цикл бесконечный, с животными или
пользовательским содержимым; музыкальная последовательность слов и финальное
затухание оригинала не перенесены. Короткие линии рисуются для ограниченного
набора кандидатов; точный отбор первых подходящих частиц оригинала не копируется.

В GLSL используются аппаратные тригонометрические функции вместо JS-таблицы
синусов. Для проверки переноса существует независимый CPU-интегратор;
сравниваются реальные данные transform feedback, а не скриншоты.

## 4K и частота кадров

`ParticleView` создаёт поверхность 3840×2160, `DisplaySetup` запрашивает
физический 4K-режим, ближайший к 60 Гц. На дисплеях без такого режима буфер
остаётся 4K и композитор может его уменьшать — это не физическое 4K-изображение.
Подсказка `Surface.setFrameRate` и continuous GLSurfaceView не гарантируют 60 FPS.

На GPU перенесены и поле скоростей, и интеграция 200 тысяч частиц. Поле
вычисляется transform feedback, поступает в RG32F texture через pixel-unpack
buffer, затем вычисляется его среднее. CPU обновляет только восемь вихрей.
Ни расширение для float framebuffer, ни compute shaders не нужны: достаточно
OpenGL ES 3.0. Точки рисуются сразу в конечную 4K-поверхность.

Диагностика `ParticlesPerf` сообщает размер буфера, частоту draw callbacks
и время CPU-подготовки/отправки команд. Это не GPU execution time и не доказательство
показанных кадров. Для FPS используются отдельно данные SurfaceFlinger.

При обычной паузе EGL-контекст сохраняется; если система его уничтожила,
вся сцена перезапускается согласованно, вместе с часами и вихрями.

Основания Android: [GLES30](https://developer.android.com/reference/android/opengl/GLES30),
[GLSurfaceView](https://developer.android.com/reference/android/opengl/GLSurfaceView),
[Surface frame rate](https://developer.android.com/reference/android/view/Surface),
[OpenGL ES 3.0 spec](https://registry.khronos.org/OpenGL/specs/es/3.0/es_spec_3.0.pdf).

## Изменения 0.3 по запросу пользователя

Для текста теперь отдельно заданы8 секунд сборки,20 секунд удержания и5 секунд
распада. Для изображений —6 /3.9 /3 секунды. Физика свободного потока сохранена;
для текста усилено притяжение, увеличено демпфирование и уменьшено локальное
дрожание букв. Это намеренное изменение ради чтения, а не утверждение о
совпадении этих интервалов с оригинальным сайтом.
