# Стандартные изображения

В `apps/particle-dream/src/main/res/drawable-nodpi/` находятся четыре атласа,
сгенерированные для проекта с помощью OpenAI image generation:

- `pets.png` (2026-09-05): ретривер, курильский бобтейл и рэгдолл, сидящие целиком.
- `pet_portraits.png` (2026-09-06): крупные портреты этих трёх пород.
- `nature.png` (2026-09-06): дерево, горный массив и папоротник.
- `space.png` (2026-09-06): Сатурн, спиральная галактика и лунный серп.

Итого12 самостоятельных образов. Это сгенерированные иллюстрации, а не
фотографии конкретных животных или астрономические снимки. Приложение
разделяет атласы по чёрным промежуткам и превращает яркость в облака точек.

Своя картинка заменяет стандартный набор до её удаления. Цитаты при этом
могут продолжать показываться. Материалы с сайта «Взаперти» в APK не включены.
