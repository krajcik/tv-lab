# Стандартные изображения

`apps/particle-dream/src/main/res/drawable-nodpi/pets.png` — изображение,
сгенерированное 2026-09-05 с помощью OpenAI image generation для этого проекта.
В нём три контрастные сцены на чёрном фоне: золотистый ретривер, курильский
бобтейл с коротким хвостом и рэгдолл.

Это иллюстрации пород, а не фотографии конкретных домашних животных.
Приложение выделяет три области атласа и переводит их в облака точек.
По умолчанию сцены чередуются; фразы выключены. Импортированная картинка
заменяет стандартный набор до её удаления.

Материалы с сайта «Взаперти» в APK не включены.
