# Устройство «Потока»

`ParticleDreamService` подключает `ParticleView` к системному режиму заставки.
Вход с пульта завершает неинтерактивный dream. Отдельная `PreviewActivity`
показывает ту же анимацию и возвращается назад стандартной кнопкой.

`ParticleEngine` — независимый от Android Java-класс. Он обновляет поле скоростей
на сетке 65×37, интерполирует его для частиц и добавляет притяжение к точкам
текущего образа. Время шага ограничено: возврат после паузы не вызывает скачок
через несколько сцен. Цели слегка перемещаются, часть частиц остаётся в потоке.
Случайное зерно задаётся явно, что позволяет повторять тестовые сценарии.

`SceneFactory` рисует фразы в `Bitmap` и выбирает точки по яркости. Изображения
преобразуются с учётом яркости и локального контраста. Порядок точек перемешан,
чтобы при сборке не возникали регулярные полосы. Стандартные сцены — три сгенерированных изображения животных из локального
атласа pets.png. Границы областей проходят по чёрным промежуткам между животными;
портреты превращаются в точки при запуске.

`ParticleRenderer` рисует GLES2 `GL_POINTS` с мягкими краями. Следы хранятся
в отдельной framebuffer texture: сохранение swap buffers драйвером не требуется.
Рабочая текстура ограничена 1280×720 и масштабируется на экран; высокая плотность
частиц требует отдельного измерения на реальном ТВ. Запросы кадров идут примерно
30 раз/с. GLSurfaceView приостанавливается вместе с preview/dream; при потере
EGL-контекста GPU-ресурсы создаются заново.

`SettingsActivity` использует стандартные Android Views, чтобы обойтись без
дополнительных библиотек. Импорт изображения выполняется в отдельном потоке,
ограничивает размер исходных байтов и декодирует уменьшенную картинку. Framework ImageDecoder (API 28+) учитывает EXIF
поворот и зеркальное отражение; дополнительные библиотеки не требуются.
Запись во внутреннее хранилище атомарна. Оригинальный файл пользователя не меняется.

## Границы первого выпуска

- Содержание задаётся непосредственно на телевизоре: фразы и одна картинка.
  Редактора с телефона, удалённой панели и импорта коллекции пока нет.
- При отключении всех сцен используются стандартные животные, чтобы заставка
  не осталась без целевого образа.
- Приложение не назначает себя системной заставкой без выбора пользователя.
- Настройка энергосбережения телевизора и проверка конкретной Philips-прошивки
  не входят в Android-код.
