# Проверка первой macOS-версии

Дата: 2026-09-06. Компьютер: Apple M4 Pro, macOS 15.1, arm64.
Сборка: Swift 6.0.3, SDK 15.2 из Command Line Tools; дополнительных зависимостей
не устанавливалось. Android-код и каталог версии 0.4.0 сохранены.

## Выполненные проверки

- `tools/build-macos.sh`: успешно собраны `.saver` и preview `.app`; обе локальные
  подписи прошли `codesign --verify --strict`.
- `tools/test-macos.sh`: PASS, все 100 разных изображений и 1000 цитат дают
  непустые облака нужного размера; все цитаты помещаются по ширине.
- Кеш: 40 последовательных переходов, максимум 3 удерживаемых облака; устаревший
  результат фоновой задачи не восстанавливает кеш после закрытия.
- Сравнение с существующим Java CPU-движком: 256 частиц, 120 одношаговых образцов
  через каждую секунду двух минут модельного времени (7200 CPU-шагов, отдельные
  image/text сценарии). Максимальная разница всех компонентов `4.7683716e-7`,
  при пороге `1e-4`. Сценарии охватывают сборку, удержание, распад и свободный поток.
- Ранее пробовалось сравнение блоками по 60 шагов: максимум позиции 0.001025,
  скорости 0.08531. Побитовая сходимость длинных хаотических траекторий не заявляется:
  Java использует double для тригонометрии и среднего, GPU — float. Проверка
  отдельного шага отделяет уравнения переноса от накопления численных различий.
- Отрисованы настоящие 200000 частиц в текстуру 3840×2160: по 1080 кадров
  изображения и цитаты, все Metal command buffers завершились без ошибки.
  Последний полный запуск: 1.4191 с и 1.1029 с соответственно. Это пропускная
  способность вне экрана, а не измеренная частота показа монитора.
- Скриншоты собственной Metal-текстуры проверены визуально: ретривер узнаваем,
  кириллица читается и ориентирована правильно. Первоначальное отражение текста
  по вертикали исправлено до установки.
- `.saver` динамически загружен отдельным процессом через `Bundle`; проверены
  principal class `FlowScreenSaver`, создание Metal и повторные start/stop.
- Независимое чтение кода не выявило конкретных ошибок кеша, жизненного цикла
  или Metal-буферов. Это дополняет тесты, но не заменяет проверку системного хоста.

## Показ на экране

В финальном 45-секундном полноэкранном предпросмотре drawable был 3456×2160,
200000 частиц. Получено 2614 отправленных кадров за 45.2377 с (57.78 отправок/с).
`MTLDrawable.presentedTime` дал положительные значения только для 242 кадров
на отрезке 4.4667 с: 53.96 FPS, медиана интервала 16.667 мс, p95 20.833 мс.
Выборка фактического показа короткая; устойчивые 60 FPS не подтверждены.
Предыдущий двойной таймер давал лишние отправки; он удалён, используется
единственный планировщик `ScreenSaverView`.

## Установка и границы проверки

Установлен `~/Library/Screen Savers/Flow.saver`; подпись проверена, бинарник
совпадает со сборкой. В ByHost `com.apple.screensaver` записаны `moduleDict`
для Flow и `idleTime=300` (5 минут), прежние настройки предварительно сохранены
локально в игнорируемом `.toolchain/macos-preferences-before.plist`.

Запуск `ScreenSaverEngine` не дал подтверждения загрузки Flow в системный
`legacyScreenSaver`. Управление System Settings через `osascript` запрещено
macOS Accessibility (`-1719`). Открыт раздел «Заставка»; окончательный выбор
плитки «Поток · TV Lab» оставлен пользователю. Запись legacy preferences сама
по себе не доказывает выбор в современной macOS. Автозапуск при бездействии
пока не проверен.

Не проверены другие Mac/macOS, длительная работа на батарее, несколько дисплеев
и полный цикл сна/пробуждения. Mac-версия пока имеет фиксированные настройки
каталога и 200000 частиц, без Android UI импорта. Сборка ad hoc для локального
использования, без Developer ID/notarization.
