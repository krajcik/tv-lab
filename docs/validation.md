# Проверки версии 0.2.0

Дата: 2026-09-05. Хост macOS arm64, JDK 21.0.12.1, Apple M4 Pro.
Android Emulator 37.1.11, образ Android TV 14 arm64, GPU `host`,
физический режим эмулятора **3840×2160, 60.000004 Гц**, density 640.
Это не испытание на Philips 65PUS8729/60.

## Сборка и корректность

- `./gradlew --no-daemon :particle-dream:assembleDebug :particle-dream:assembleDebugAndroidTest :particle-dream:lintDebug`
  — **BUILD SUCCESSFUL**. Lint: **0 ошибок, 2 предупреждения**: доступен более
  новый Gradle; ParticleView создаётся программно с готовым engine, без
  конструктора для XML layout editor. Ошибки не подавлялись.
- `bash tools/test-engine.sh` — **PASS**: детерминированное поле, индивидуальный
  захват около 15-й секунды, сходимость к цели, 60 секунд моделирования через
  смену вихрей, отражение от стен, ограничение скачка времени после паузы.
- `bash tools/test-android.sh emulator-5580` — **PASS**: стандартные животные,
  запуск настроек, импорт JPEG с EXIF-поворотом, сохранность оригинала,
  замена стандартных сцен своей картинкой, сохранение прежней картинки при
  неудачном импорте и возврат животных после удаления пользовательской копии.
- Тот же Android-тест сравнил **реальное GPU transform-feedback состояние**
  с независимым CPU-интегратором: 256 частиц, 340 шагов по 0.045 с, включая
  сборку образа. Максимальная разница компонентов состояния **0.000006143**,
  допуск теста 0.002. Поле также вычислялось на GPU, не подставлялось с CPU.
- `git diff --check` — без ошибок.

## Производительность 4K

Проверялось **200 000 частиц**, настоящая поверхность и viewport 3840×2160,
без промежуточного framebuffer и без понижения разрешения.

Первый вариант с расчётом поля на CPU давал 15–24 draw callbacks/с, поле
занимало 35–60 мс. После переноса поля на GPU CPU-часть занимает около
0.02–0.03 мс, общая CPU-подготовка/отправка команд около 0.11–0.13 мс.
Эти числа не являются временем выполнения GPU-команд.

В первоначальном 30-секундном прогоне SurfaceFlinger сообщил averageFPS 55.529.
В контрольном прогоне после закрытия браузера с оригинальным эффектом:

- SurfaceFlinger зарегистрировал **1801 кадр слоя за примерно 30 секунд**,
  что соответствует примерно **60 FPS**.
- Последовательные пятисекундные окна draw callbacks: **59.8–60.0/с**.
- Отдельная выборка `SurfaceFlinger --latency` из **127 времён показа** дала
  **59.545 FPS**; медианный интервал **16.649 мс**, максимальный **31.082 мс**.
  Это короткая выборка примерно за 2.1 секунды, а не гарантия отсутствия просадок.
- Встроенный histogram-based averageFPS контрольного timestats равен 61.860.
  Его нельзя трактовать как физические 61.86 Гц на 60-Гц дисплее: он не совпадает
  с счётчиком кадров/временем наблюдения. Выше приведены отдельные исходные
  показатели и результат по временным меткам.

Улучшение после закрытия браузера наблюдалось, но отдельный причинный эксперимент
с нагрузкой браузера не проводился. На Mac результат — **около 4K/60**, а не
обещание неизменных 60 FPS при любой нагрузке.

## Ограничения

Отдельно проверен **системный DreamService 0.2**, а не только предпросмотр:
таймер бездействия запустил наш компонент, `isPreview=false`, `mBound=true`.
В позднем 20-секундном замере его SurfaceView показал 1096 кадров (около
54.8 FPS по длительности наблюдения; histogram-based averageFPS=56.059).
Пятисекундные окна draw callbacks в этот период колебались от 43.8 до 58.6.
Причина отличия от контрольного предпросмотра не установлена. Следовательно,
стабильные 60 FPS во всех режимах эмулятора пока **не подтверждены**.

На физическом Philips APK ещё не устанавливался. Не измерены его GPU,
нагрев, длительная стабильность и доступность выбора сторонней заставки
в меню прошивки. Поддержка декодирования 4K-видео не доказывает достаточную
скорость этой 3D-сцены. В приложении доступны 50/100/200 тысяч частиц; их
нужно проверять на самом телевизоре.

В эмуляторе стандартный intent `android.settings.DREAM_SETTINGS` не открывает
Activity. Для испытания системного dream компонент задаётся только в тестовом
Android через ADB. Приложение само защищённые настройки не меняет.
